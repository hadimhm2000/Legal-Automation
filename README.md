# Legal-Automation — ربات «اتوماسیون ویژه خدمات حقوقی» (ربات دوم بله)

ربات بله‌ی مستقل (پایتون، aiogram 3 + Playwright) که با اطلاعاتی که کاربر **همان لحظه و مرحله‌به‌مرحله** می‌دهد
(کدملی ← رمز شخصی ← رمز موقت) وارد سامانه‌های عدل ایران می‌شود. **اطلاعات ورود ذخیره نمی‌شود.**
از ربات اصلی (`online.judicial.services.ble`) فقط با یک دکمه‌ی مخصوص مدیر و لینک امضاشده وارد می‌شویم.

## راه‌اندازی

```sh
python -m venv .venv && . .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium            # لینوکس: playwright install-deps chromium
cp env.example .env                    # مقادیر را پر کنید
python bot_main.py
```

در ربات اصلی (`online.judicial.services.ble`) در `.env`: `LEGAL_BOT_USERNAME` و همان `HANDOFF_SECRET`.

## مرورگر قابل‌مشاهده و رفتار انسانی

- **پیش‌فرض `HEADLESS=0`**: پنجره‌ی مرورگر باز می‌شود تا رفتار ربات را ببینید. پنجره در
  **گوشه‌ی بالا-چپ** با اندازه‌ی `1366×900` باز می‌شود تا با پنجره‌ی ربات اصلی (وسط صفحه) قاطی نشود
  (قابل تغییر با `BROWSER_WINDOW_POSITION` / `BROWSER_WINDOW_SIZE`).
  روی سرور بدون نمایشگر، خودکار به headless برمی‌گردد.
- **سرعت انسانی**: تایپ هر نویسه ۱۲۰–۲۴۰ms تصادفی، مکث ۱٫۵–۳ ثانیه بین مراحل، مکث بعد از لود کامل
  هر صفحه. برای کندتر/سریع‌تر کردن کل ربات: `SPEED_FACTOR` (مثلاً `1.5`).
- **انتظار برای لود کامل و CTA**: بعد از جستجو/کلیک، تا سقف `SEARCH_WAIT_MS` (۲۵ ثانیه) صبر می‌کند
  تا نتیجه واقعاً ظاهر شود (کارت‌ها یا پیام «یافت نشد»)؛ اگر سامانه سریع بود همان لحظه ادامه می‌دهد.
- **چاپ PDF در حالت قابل‌مشاهده**: `page.pdf()` فقط در headless کار می‌کند؛ برای همین PDFگیری از طریق
  CDP (`Page.printToPDF`) انجام می‌شود که در هر دو حالت جواب می‌دهد.

## رفع خطای ارسال فایل به بله (L11)

aiogram فایل‌ها را با ارجاع `attach://file0` می‌فرستد؛ **API بله این مکانیزم را نمی‌فهمد** و خطای
`TelegramBadRequest: Bad Request: failed to get HTTP URL content` می‌دهد (در مرحله‌ی L11 «ارسال به کاربر»).
راه‌حل: `BaleDirectUploadSession` (`legal_bot/services/bale_session.py`) بایت‌های فایل را مستقیماً زیر
نام خود فیلد (مثل `document`) می‌فرستد — همان قالب curl و مستندات بله. تلگرام هم این قالب را می‌پذیرد.
علاوه بر آن، `send_pdf` تا ۳ بار تلاش می‌کند و خطای ارسال در گزارش مدیر به‌جای `UNKNOWN` (اقدام: توقف)
به‌صورت `SEND_FAILED` (اقدام: ثبت در گزارش) ثبت می‌شود و به کاربر پیام روشن می‌دهد که مشکل از
پیام‌رسان بوده نه سامانه‌ی عدل.
