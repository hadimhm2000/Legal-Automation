# پنل مدیریت وب (legal_admin)

داشبورد مدیریتی مستقل برای ربات «اتوماسیون ویژه خدمات حقوقی» که **موازی با ربات** روی همان
دیتابیس SQLite (WAL) اجرا می‌شود. طراحی متفاوت از پروژه‌ی مرجع است: سایدبار راست + تم گرافیت
تیره/زمرد، بدون نیاز به Node.js.

## اجرا روی ویندوز

1. پچ را اعمال کنید (از ریشه‌ی مخزن): `git apply legal-admin-panel.patch`
2. وابستگی‌ها: `.venv\Scripts\pip.exe install -r requirements.txt`
3. در `.env` این مقدارها را تنظیم کنید (پورت ۸۳۰۰ عمداً دور از ۳۰۰۰ و ۳۱۰۰ است):

```
ADMIN_PANEL_PORT=8300
ADMIN_PANEL_PASSWORD=<یک رمز قوی>
```

4. اجرا: `run_admin_panel.bat` → پنل روی `http://<IP سرور>:8300` بالا می‌آید.
   ربات می‌تواند در همان لحظه روشن باشد (هر دو یک فایل دیتابیس را با WAL می‌خوانند/می‌نویسند).

## امکانات

- **داشبورد**: کاربران، مشترکین فعال، فاکتورهای در انتظار، درآمد ۷ روزه، بررسی‌ها/خطاهای
  ۲۴ ساعت اخیر، نمودار ۷ روزه، توزیع پلن‌ها و آخرین رویدادهای پلن.
- **کاربران**: جستجو (آیدی/نام/موبایل)، فیلتر پلن و وضعیت؛ جزئیات کامل کاربر (اشتراک،
  فاکتورها، پرونده‌ها، رویدادها)؛ محدودسازی/برداشتن محدودیت (همان قاعده ۶ ربات).
- **فاکتورها**: تأیید / رد با دلیل / اعلام کسری — دقیقاً با همان توابع
  `legal_bot.services.subscription` که دکمه‌های داخل بله استفاده می‌کنند؛ پیام به کاربر هم
  از طریق بله ارسال می‌شود (فاکتور «نوبت قضائی» دکمه‌ی شروع ثبت نوبت را هم می‌فرستد).
- **بررسی‌ها / خطاها / ابلاغیه‌ها / پرونده‌های پیگیری**: جدول‌های صفحه‌بندی‌شده با فیلتر.
- **پیام همگانی**: همه / فعال / پرداختی / رایگان / بتا — نرخ ۲۰ پیام در ثانیه.
- **پیام به یک کاربر**: از صفحه‌ی پیام همگانی.
- **فهرست بتا**: افزودن/حذف بدون دستور `/legal_allow` داخل بله.
- **تنظیمات**: قیمت‌ها، سقف‌ها، زمان‌بندی و کارت (شماره‌ی کارت ماسک می‌شود).

## امنیت

- ورود با `ADMIN_PANEL_PASSWORD`؛ نشست امضاشده HMAC در کوکی HttpOnly (پیش‌فرض ۱۲ ساعت).
- ۵ ورود ناموفق از یک IP = ۱۰ دقیقه قفل.
- همه‌ی درخواست‌های POST هدر ضد CSRF لازم دارند؛ توکن ربات هرگز در پاسخ‌ها برنمی‌گردد.
- پیشنهاد: اگر پنل فقط از خود سرور باز می‌شود، `ADMIN_PANEL_HOST=127.0.0.1` بگذارید.

## نکته‌ها

- اگر ربات روشن باشد و پنل هم، دیتابیس WAL هر دو را بدون قفل نگه می‌دارد.
- فایل لاگ پنل: `logs/admin_panel.log`.
- پورت را با `ADMIN_PANEL_PORT` عوض کنید (۳۰۰۰ و ۳۱۰۰ به پروژه‌های دیگرتان تعلق دارند).
